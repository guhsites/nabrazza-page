🍔 Nabrazza — Landing Page
  Landing page desenvolvida para a Nabrazza, uma hamburgueria com identidade visual moderna e foco na apresentação de seus produtos.

📌 Sobre o projeto
  A Nabrazza é uma landing page criada para representar a presença digital de uma hamburgueria, destacando sua marca e proporcionando uma experiência de navegação agradável.
  O projeto faz parte da minha jornada de aprendizado em desenvolvimento front-end, colocando em prática conceitos de estruturação, estilização e organização de páginas web.

🚀 Tecnologias utilizadas
  🟠 HTML5 — estrutura e organização do conteúdo.
  🔵 CSS3 — estilos, cores, tipografia e layouts.

✨ Funcionalidades
  🍔 Apresentação visual da hamburgueria.
  🎨 Identidade visual personalizada.
  📱 Layout responsivo, caso implementado.
  📋 Seções para apresentação dos produtos.
  📞 Área de contato ou pedidos, caso implementada.

⚙️ Como executar o projeto
  1.Abra o Arquivo 'index.html' no navegador.
